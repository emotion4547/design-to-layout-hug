
# Оптимизация скорости загрузки и работы сайта

## Что сейчас замедляет сайт

1. **Все страницы загружаются сразу** -- в `App.tsx` все 20+ страниц импортируются статически, включая весь админ-раздел, даже если пользователь заходит только на главную.

2. **Изображения не оптимизированы** -- все картинки товаров (`bouquet-1.jpg` ... `bouquet-8.jpg`) загружаются как есть, без lazy loading и без адаптивных размеров.

3. **Внешний iframe (Яндекс.Отзывы)** загружается сразу при открытии главной страницы, блокируя рендер.

4. **Множество отдельных запросов к настройкам** -- Header делает 5 запросов `useSetting()`, Footer ещё 8, Hero ещё 5. Каждый -- отдельный запрос к базе данных.

5. **Тяжёлые анимации** (Snowfall, FallingPetals, Confetti, Fireworks) рендерят десятки DOM-элементов с CSS-анимациями.

---

## План оптимизации

### 1. Lazy Loading страниц (code splitting)
Все страницы, кроме главной, загружаются по требованию через `React.lazy()`. Это сократит начальный бандл в 2-3 раза.

```text
Было: import Catalog from "./pages/Catalog"
Стало: const Catalog = lazy(() => import("./pages/Catalog"))
```

Все admin-страницы, страницы новостей, акций, корзины, контактов -- станут загружаться только при переходе на них.

### 2. Lazy loading изображений
Добавить `loading="lazy"` ко всем тегам `<img>` в компонентах: ProductCard, News, CollectionCards, Hero. Браузер не будет загружать картинки за пределами экрана.

### 3. Отложенная загрузка Яндекс.Отзывов
Компонент `YandexReviews` будет загружать iframe только когда пользователь до него доскроллит (через `IntersectionObserver`). Это убирает тяжёлый iframe из начальной загрузки.

### 4. Объединение запросов настроек
Создать единый хук `useAllSettings()`, который загружает все настройки одним запросом к базе вместо 15-20 отдельных. Header, Footer и Hero будут использовать данные из одного запроса.

### 5. Оптимизация React Query
Увеличить `staleTime` и добавить `gcTime` для данных, которые редко меняются (категории, настройки), чтобы избежать повторных запросов при навигации.

---

## Ожидаемый результат

- Начальная загрузка: быстрее в 2-3 раза (меньше JS-кода)
- Меньше сетевых запросов (1 вместо 15+ для настроек)
- Изображения загружаются только при прокрутке
- Яндекс.Отзывы не тормозят начальный рендер
