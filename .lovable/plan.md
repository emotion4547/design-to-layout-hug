

# SEO-упаковка главной страницы

## Что сейчас не так

1. **Title**: `Главная | Везу букет` -- слово "Главная" не несёт SEO-ценности, поисковики его игнорируют
2. **Формула title**: на главной странице бренд должен стоять первым, а не через `|`
3. **Description**: хорошее, но можно усилить коммерческими триггерами (бесплатная доставка, круглосуточно и т.д.)
4. **Keywords**: набор неплохой, но не хватает длиннохвостовых запросов ("купить букет Новороссийск", "цветы с доставкой")

## Что будет сделано

### 1. Новый title главной страницы

Вместо `Главная | Везу букет` будет:

**"Везу букет — Доставка цветов и букетов в Новороссийске"**

Это совпадает с тем, что уже стоит в `index.html` (для ботов без JS), и является оптимальным: бренд + главный поисковый запрос + город.

Для этого на главной `title` будет передаваться пустым (используется fallback из `SEO.tsx`), либо будет задан специальный формат без разделителя `|`.

### 2. Усиленный description

Текущий:
> Доставка свежих цветов и букетов в Новороссийске. Розы, тюльпаны, авторские композиции, букеты в шляпных коробках. Быстрая доставка по городу.

Новый (до 160 символов, с коммерческими триггерами):
> Доставка свежих цветов и букетов в Новороссийске. Розы, авторские композиции, букеты в шляпных коробках. Доставка от 1 часа. Заказ онлайн и по телефону.

### 3. Расширенные keywords

Добавить длиннохвостовые запросы:
- купить букет Новороссийск
- цветы с доставкой Новороссийск
- заказать цветы онлайн
- букет роз с доставкой
- цветочный магазин Новороссийск

### 4. Логика SEO.tsx для главной

В компоненте `SEO.tsx` изменить логику формирования title: если `title` не передан, использовать fallback `Везу букет — Доставка цветов и букетов в Новороссийске` (без разделителя `|`). Это уже реализовано в текущем коде, поэтому достаточно убрать `title="Главная"` из `Index.tsx`.
