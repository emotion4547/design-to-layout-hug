# Changelog

## 2026-05-06

### Безопасность
- Закрыт публичный INSERT в `integration_logs`: запись теперь только из edge-функций под service role (`WITH CHECK (false)` для anon/authenticated).
- Подтверждена админ-only видимость `order_items` (публичного SELECT нет).
- Включена защита от утёкших паролей (HIBP) в настройках авторизации.
- Обновлена `@security-memory`: задокументированы намеренные публичные доступы (витрина, гостевой чекаут, `verify_jwt=false` для edge-функций) и принятый риск по `xlsx` (используется только админами).

### SEO
- Заменено "Бутон в тон" на "Везу букет" во всех мета-тегах, заголовках и описаниях страниц (`SEO.tsx`, `Favorites`, `Contacts`, `Cart`, `TermsOfUse`, `ReturnPolicy`, `News`, `Collection`, `index.html`).
- Оптимизирован title главной страницы: убрано слово "Главная", задан брендовый формат `Везу букет — Доставка цветов и букетов в Новороссийске`.
- Усилен description главной: добавлены коммерческие триггеры ("Доставка от 1 часа", "Заказ онлайн и по телефону").
- Расширены keywords длиннохвостовыми запросами: "купить букет Новороссийск", "цветы с доставкой Новороссийск", "заказать цветы онлайн" и др.
- Синхронизированы статические meta-теги в `index.html` с динамическими.
- Заменён `og-image.jpg` на новый брендовый баннер.

### Яндекс.Директ / товарный фид
- Добавлена edge-функция `yandex-yml`, генерирующая YML-фид по требованиям Яндекс.Директа (`yml_catalog/shop/categories/offers`, валюта RUR, абсолютные URL, XML-экранирование).
- Фид автоматически обновляется из БД (только активные категории и товары `in_stock`), кэширование 1 час.
- Постоянный URL фида: `https://ljkfuyxxxaqevsxeswrv.supabase.co/functions/v1/yandex-yml`.
- В админке (`/admin/products`) добавлены кнопки **"Скачать YML (Яндекс)"** и **"Ссылка на фид"** для копирования URL.
- Поддержан параметр `?download=1` для прямой загрузки файла.
